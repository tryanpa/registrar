How it works

Getting a domain

  1. Sign up
    Create an account. Your name is shown in WHOIS.
  2. Search
    Find a name that's free under {% for t in cfg.tlds %}.{{ t }}{% if not loop.last %} or {% endif %}{% endfor %}.
  3. Request it
    Enter your web server's IP address. You can hold up to {{ cfg.max_domains }} name{{ 's' if cfg.max_domains != 1 }} at a time.
  4. Wait for approval
    Your instructor reviews it. Once approved, it's live in DNS within seconds.
  5. Visit your site
    Open http://yourname.{{ cfg.tlds[0] }} in a browser on the lab network.

Check it from the command line

Ask the lab's DNS server ({{ cfg.dns_server }}):

dig +short mysite.{{ cfg.tlds[0] }}
dig mysite.{{ cfg.tlds[0] }} @{{ cfg.dns_server }}

Look up the registration record:

whois -h {{ cfg.registrar_host }} mysite.{{ cfg.tlds[0] }}

Remember: type http://mysite.{{ cfg.tlds[0] }} in full, or your browser may treat it as a search.

If it isn't working

  • Is the request approved? Check My domains.
  • Does dig +short show your VM's IP? If not, check the IP you entered.
  • Does the IP answer? Try ping and curl http://<ip>.
  • Is your web server listening on port 80 and not blocked by a firewall?
  • Does your VM use {{ cfg.dns_server }} as its DNS server?

Naming rules

  • 3-40 characters: letters, numbers and single hyphens.
  • No hyphen at the start or end.
  • Some names are reserved for lab infrastructure.
  • www.yourname.{{ cfg.tlds[0] }} automatically points to the same place.
    • {% if cfg.max_records > 0 %}
  • Once your name is approved you can add up to {{ cfg.max_records }} subdomains, like blog.yourname.{{ cfg.tlds[0] }}, under My domains. Point one at an IP address (A record) or make it an alias of another of your names (CNAME).
